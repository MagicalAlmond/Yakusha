# 支持的游戏与实测

哪些游戏跑通过、文本量多大、游戏目录怎么找、官中游戏怎么处理。

本页的实测游戏只记录匿名编号（MZ-A … MV-H）和汇总数字，**不记录游戏标题、截图或任何游戏
文本**；唯一的例外是 Ren'Py 的两个官方示例游戏，它们是 SDK 自带的公开样例，直接写名字。
运行时确认都是本机临时注入、验完即删，仓库里不存游戏内容。

其中 **4 款跑完过一次全量翻译**（合计 71,254 条唯一串），并在真实游戏里确认中文
出现在对话框里：

| 游戏 | 引擎 | 唯一串 | 译完 | `verify` 的 error |
| --- | --- | --- | --- | --- |
| MZ-A | MZ 1.7.0 | 38,044 | 38,042 | 0 |
| MZ-C | MZ 1.7.0 | 24,757 | 24,735 | 0 |
| MV-G | MV 1.6.2 | 4,388 | 4,387 | 0 |
| MV-H | MV 1.6.2 | 4,065 | 4,064 | 0 |

剩下的 2 / 22 / 1 / 1 条是校验主动拒收的（全角空格、纯拟声词里保留的「ッ」、
`\N<名字>` 这种只有假名人名的行），运行时插件对它们回退显示原文——宁可留一句日文，
也不留一句可能错位的译文。

**游戏根目录不必正好指对。** 分发出来的游戏布局五花八门：有的外面套一层 `www/`
（MV 常见），有的把真正的游戏放进一个改名子目录，还有的额外带一份 `data/www/`
浏览器构建。`findProjectRoot` 会从你给的目录往下**有界搜索**（最多 3 层，跳过
`node_modules`、`img`、`audio` 这类资源目录），找到最浅的那一个；如果同一层有两个
游戏，它会报错并列出候选，而不是随便挑一个。

Ren'Py 侧对应的是 `findRenpyRoot`，认的目录形状是 `game/` 里放着 `.rpy` 或 `.rpyc`：同样
往下最多 3 层有界搜索，最浅那一层出现两个项目就报 `E_MULTI_ROOT` 并列出候选；`detect` 还会
先从你给的目录往上找最多 3 层，所以指到启动器目录或 `game/` 本身都能命中。

**已经是目标语言的游戏不必全量翻。** 官方中文版里绝大多数条目本来就该原样留着，
送进模型既费 token 又可能被改写（本机两款官中游戏 MZ-G / MV-H 里不含假名的条目
分别是 6,788/6,797 与 3,994/4,018，抽样看过去基本都是现成的中文）。本项目**不做自动
语言检测**——实测"没有假名"这一条判不出来：日文原版 MZ-A 里 437 条无假名条目就有
「武闘家」「騎士」「鎧系」「盾系」这类纯汉字日文，用日文特有汉字集合加严后仍会误跳过
64% 的日文条目。误跳过意味着玩家直接看到日文，代价远高于多花的那点 token。所以流程是：
全量跑，模型对已经是中文的句子会原样回显，随后的"原样回显"闸门把它拒收（记 `error`、
保持未翻译），不会写进错误译文；想省钱就先用 `--limit` 抽样，看 `status` 的拒绝率
再决定。

抽样判断的具体做法（以官方中文游戏为例）：

```bash
node bin/yakusha.js extract "/games/SomeGame"
node bin/yakusha.js translate "/games/SomeGame" --limit 200     # 只翻 200 条
node bin/yakusha.js status "/games/SomeGame"
```

`status` 里的 `withError` 绝大多数就是"原样回显被拒"的条目。**拒绝率高说明这款游戏
本来就是中文**——全量跑只会白花 token 并把每一条都记成 `error`，此时直接
`install` 装插件即可（插件对没翻的条目回退原文，玩家看到的就是官中原文）。
拒绝率低则说明是日文原版，再跑全量。Ren'Py 下对应的是 `install` 写
`game/yakusha_translation.rpy`：只有字典里已翻译的条目会进这个文件，没翻的条目引擎照读原文，
玩家看到的同样是官中原文。

## Ren'Py

本机没有真实 Ren'Py 游戏，Ren'Py 的验收用的是 Ren'Py 8.5.3 SDK 自带的两个官方示例游戏
（`the_question`、`tutorial`），两者都带完整 `.rpy` 源码，统计按源码算：

| 示例游戏 | 脚本数 | 唯一串 | 出现次数 | `undecodable` |
| --- | --- | --- | --- | --- |
| `the_question` | 5 | 202 | 229 | 0 |
| `tutorial` | 24 | 1,101 | 1,217 | 0 |

两个示例的 `.rpy` 与 `.rpyc` 是一一对应的（各 52 对、236 对），工具按源码读、同名的编译
文件跳过，所以 `scripts` 里 `rpyc` 是 0；`.rpyc` 单独存在的那条路只有测试夹具覆盖（见
`test/fixtures/renpy-rpyc/`）。`game/tl/` 下还各有 47 / 212 个 `.rpy`，分在 12 / 10 个语言目录里
（随 SDK 附带的示例译文：两种文件——`common.rpy`、`screens.rpy`、`options.rpy`
翻的是引擎 UI 字符串，`script.rpy`、`indepth_*.rpy`、`tutorial_*.rpy` 等翻的是游戏自己的台词），
扫描时整个 `tl/` 目录跳过。

**这不等于对商业 Ren'Py 游戏的验收**：本机没有任何真实 Ren'Py 发行版可跑，打包过的游戏、
带第三方 `tl/` 补丁的游戏都还没有实测数字。

Ren'Py 的安装产物是一个文件：`install` 写 `game/yakusha_translation.rpy`，`uninstall`
删掉它，原脚本一个字节都不动，删文件即恢复。

## 不支持的引擎

XP/VX/VX Ace（`.rxdata` 二进制）、Unity/Godot/Kirikiri 等其它引擎。
